# v0.1.0-alpha.1

First public native-bridge research release.

## Included

- Project-authored `mc_dlss_bootstrap.dll` and `mc_dlss_native.dll`.
- AMD-signed FidelityFX SDK 2.3.0 loader, upscaler, and frame-generation runtimes.
- License, third-party notice, provenance, and SHA-256 files.

## Important

This is not a ready-to-install Minecraft mod release. The custom project DLLs are unsigned and may be blocked by Windows App Control. Do not disable Windows security features to run them.

The release exists to establish a reproducible FSR3-only build and the artifact shape that will later be submitted for Authenticode signing. NVIDIA Streamline and DLSS runtime files are intentionally excluded.
